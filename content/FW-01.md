# FW-01: First Firmware Setup

This task involves setting up the initial repository structure for a new firmware project.

## Requirements
1. Initialize a new Rust project using `cargo init`.
2. Add `serde` and `serde_json` to `Cargo.toml`.
3. Create a basic `main.rs` that prints "Hello, World!".
